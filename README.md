# omni-todo

> A silly little todo app that uses too many web frameworks.

[View the live website](https://43081j.com/omni-todo/).

## What is this?

Some nonsense. It is a todo app implemented using the following web frameworks:

- React
- Lit
- Preact
- Solid
- Svelte
- Vue

Each of these owns one or more parts of the page, and each of them are exposed
as web components (custom elements).

Although it is nuts, it is a fun experiment to see how well these frameworks can coexist on the same page.
